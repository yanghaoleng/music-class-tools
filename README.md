# 音乐班 · Music Class Tools

服务于音乐线下教学小班的一组小工具，覆盖课前排课、课堂演奏展示，以及课后找谱、收谱与跟吹练习。

由羊子科技制作。各应用独立运行，放在同一个仓库中维护，方便围绕老师、学员和家长的日常使用持续改进。

## 工具一览

| 工具 | 面向的场景 | 主要能力 | 体验 |
| --- | --- | --- | --- |
| **小节 · 音乐班排课** | 教室管理员、老师、学员及家长的课程安排 | 多身份权限、月/周/3 天课表、拖动调课、预约确认、课时余额、课堂反馈与语义排课 | [打开小节](https://m.mikeywa.site/cal/) |
| **NoteType** | 课堂演奏展示、演奏片段回顾 | 从演奏视频提取音符、匹配参考曲谱、校正音符，导出带同步五线谱的演奏视频 | [打开 NoteType](https://m.mikeywa.site/notetype/) |
| **洞洞谱** | 爱尔兰哨笛的曲谱收纳与课后练习 | 搜索、星标、私人曲谱、文本转指法、试听、音频/图片导入与麦克风跟吹评分 | [打开洞洞谱](https://m.mikeywa.site/ddp/) |
| **弦迹** | 无乐理门槛的视觉作曲与音乐探索 | 画线作曲、多音色声部、节拍音阶、本机作品保存搜索与规则分类、WAV/MIDI/作品导出 | [打开弦迹](https://m.mikeywa.site/xianji/) |
| **李老师的音乐班** | 从零基础乐理到钢琴入门的互动学习 | 7 章 56 题、音符节奏试听、虚拟琴键、AI 对话、错题重练与笔记 | [打开音乐班](https://m.mikeywa.site/pianoclass/) |

目前排课应用重点支持一对一课程的协调；整个工具集面向小型线下音乐教学场景，并不代表已经支持所有多人合班排课规则。

## 本地运行

每个应用有自己的依赖、配置和服务，进入对应目录运行即可。具体步骤、环境变量、测试和部署方法见：

- [小节使用与开发说明](cal/README.md)
- [NoteType 使用与开发说明](notetype/README.md)
- [洞洞谱使用与开发说明](ddp/README.md)
- [弦迹使用与开发说明](xianji/README.md)
- [李老师的音乐班使用与开发说明](lilaoshi/README.md)

前四个工具的前端使用 React 与 Vite；小节和洞洞谱使用 Python 后端，NoteType 使用 Node.js 与 Remotion。李老师的音乐班使用自托管静态前端与 Python 后端。涉及音视频处理时需要 FFmpeg，NoteType 的视频导出还需要 Chrome。AI 能力按各应用的说明在服务端配置，不在浏览器中放置密钥。

各应用的账户范围不同：洞洞谱与外部的体重日历共用账户；小节保留自己的教室身份与权限。这个仓库目前没有统一覆盖三个应用的登录系统。

## 数据与配置

公开仓库收纳应用源码、必要静态资源、公开来源的参考曲库和产品文档。真实学员/家长资料、课表数据库、访问口令、API Key、私人曲谱、NAS 原图与本地构建缓存不进入仓库。部署时请自行配置私有环境变量和数据目录。

本地三个子目录原有的 Git 记录仍保留；GitHub 主分支以当前工作区的公开文件快照开始，三个应用作为普通目录完整收纳，不依赖子模块。

## 曲谱与第三方资源

曲库用于旋律检索与教学练习，来源、版本和能力边界见各项目文档，尤其是 [NoteType 曲库来源](notetype/catalog/SOURCES.md) 与 [洞洞谱曲库说明](ddp/README.md#曲库)。公开可访问不等于可以任意再发行，具体曲目、编配、模型、字体及依赖的权利与许可仍以上游说明为准。

本仓库未统一授予所有源码和曲库一份额外的开源许可证；公开可读与具体使用授权请分别确认。
