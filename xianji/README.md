# 弦迹 · 把旋律画出来

羊子科技出品的画线作曲工具。正式入口：<https://m.mikeywa.site/xianji/>。

## 创作

主界面为整屏点阵画布，无方格、侧栏或应用名称。工具和文字统一使用黑灰色，纸面与按钮采用无渐变的颗粒材质；紫红色只用于笔触和图标。浮层保留 CSS backdrop-filter 的轻透层次。画笔、音色、节奏、声部、作品集、导入导出均在默认收起的模态浮层中；Motion 负责对称的打开/关闭过渡，支持焦点约束、回到触发按钮、减少动态效果、减少透明效果与高对比偏好。

左上角图标打开「画布与文件」，也可进入「图标方案」预览四款平涂蜡笔质感的涂鸦/声波矢量图标。A 为默认预览方案；选择存在本机 `xianji.icon.v1`，同步菜单图标和 favicon，可下载原始 SVG。选项素材位于 `public/icons/`，不包含外部生成服务或网络字体依赖。

在画布上拖动画线，横向位置代表时间，纵向位置映射到选定音阶的 C3–C5 两个八度范围（调性可移调）。播放线从左向右扫描，以每拍、半拍或四分之一拍为间隔，在每个间隔中心采样线条交点。每次交点发声，线条可以产生和弦；重复同音自动合并，每条线每次最多四音，总共最多 32 音。逆向画线按画布时间轴演奏，短点自动转为一个音符宽度的线段。

支持五声音阶、大调、小调，12 个调性，40–200 BPM，2/4/8 小节，循环与单轮播放。画笔颜色独立于音色，粗细影响视觉，不影响响度。五种音色是本地合成的电钢、钟琴、拨弦、空气合成器和贝斯，并非真实乐器采样。贝斯低一个八度。

笔触通过固定颗粒噪声和轻微边缘位移呈现干蜡笔质感；只改变视觉，不改变音高与时间数据。画笔提供 3/7/12 px 三档，默认 7 px。SVG 导出保留颗粒滤镜。纸面点阵使用纯色 SVG 小点平铺；界面、笔触和图标均无渐变。

每个声部指定一种音色，可调音量、静音、独奏及删除；切换声部音色会改变该声部已有线条的声音。最多 12 个声部、500 条线。支持触屏，橡皮擦除整条线；撤销/重做保留最近 40 步，删除声部也可撤销。左上角菜单的「灵感示例」提供三份原创合成示例。

快捷键：空格播放/暂停，B 画笔，E 橡皮，C 打开/关闭颜色与音色面板，⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做，⌘/Ctrl+S 保存，Esc 关闭浮层。文本输入时保留正常输入行为。切到后台自动暂停。

## 作品

草稿自动写入当前浏览器 localStorage；点击「保存作品」加入本机作品集，后续修改自动保存。切换画布时也会保留尚未手动保存的非空作品。可改名、复制、删除、搜索、按修改时间/名称/速度排序。搜索包括名称、音色和自动标签。自动分类规则：BPM <85 为慢慢流动，85–119 为轻快律动，≥120 为活力节奏；有线条的声部数量区分单声部/多声部，另附音阶标签。这些是可解释的规则，不是 AI 风格识别。

作品集最多保留最近 100 件。无登录、服务器作品库或跨设备同步；清除浏览器数据会移除本机作品。定期导出 `.xianji.json` 文件备份，也可导入另一台设备。导入限制 8 MB，校验坐标、音轨、色值、节拍和数据量。

导出包括一轮完整旋律的立体声 WAV（44.1 kHz、16-bit，附 1.5 秒尾音）、MIDI、SVG 画布以及可继续编辑的 JSON。WAV 使用与试听相同的音色引擎，保留声部静音/独奏与音量；导出主音量固定，不受监听总音量影响。MIDI 保留节拍与通用乐器映射，其他软件的声音可能不同。SVG 保留全部线条与颜色。

声音在浏览器生成，作品不上传服务器，无 AI API、麦克风权限或外部字体依赖。进入页面即开始播放扫描，新建或载入画布同样自动播放。浏览器首次自动出声可能被拦截；在首次画线或点按控件时恢复 AudioContext，无需额外点播放。未抬起的线条也实时加入音序；暂停仍可试听画笔。实体手机静音键和蓝牙延迟仍需实机观察。

## 开发与验证

```sh
npm ci
npm run dev
npm test
npm run test:browser
npm run build
```

开发入口 <http://127.0.0.1:5186/xianji/>。浏览器测试需安装 Chrome；使用隔离浏览器数据，不触碰真实作品。模型测试验证音阶、双向路径、复音、静音/独奏、节拍、规则分类、导入安全和 MIDI。浏览器测试在强制禁止无手势自动出声的模式下，验证无交互时扫描运行、首笔解锁真实音频、未抬笔实时发声、WAV、绘画/擦除/撤销、保存刷新、搜索分类、导入导出、声部、模态焦点、图标选择持久化、触屏与不同屏幕宽度。

## 部署

运行 `sh ops/deploy.sh`，默认 SSH 别名 `mikeywa-rive-old` 指向 ubuntu@115.159.25.169，可用 `XIANJI_SSH_HOST` 覆盖。发布目录 `/opt/xianji/releases/<version>`，活动链接 `/opt/xianji/current`。纯静态应用，Nginx 仅新增 `/xianji/` 路由，保留小节、NoteType、洞洞谱；无新后台服务。首次连接路由前备份 Nginx，配置检查失败自动恢复。

回滚：将 `/opt/xianji/current` 指回 `/opt/xianji/previous-release` 记录的目录。首次撤回则恢复 `/etc/nginx/m.mikeywa.site.before-xianji-*.bak`，检查 `nginx -t` 后重载。作品留在用户浏览器，回滚不操作本机数据。

参考链接为用户提供的抖音视频：<https://v.douyin.com/1KQRv5dq_Oo/>。开发环境无法播放原视频；本版依据用户描述的画布、线条和规律发声实现，没有声称逐帧复刻。

功能图标采用 [Iconoir](https://iconoir.com/)（MIT），统一 3 px 加粗描边和圆角收笔；有实心版本的播放、暂停等使用实心图标。快捷键忽略输入框、组合输入和长按重复，保留系统复制等组合键。
