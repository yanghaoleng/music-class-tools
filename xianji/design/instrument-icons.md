# Instrument sketches → SVG

内置 image_gen 先生成 `instrument-sketch-reference.png`（4 × 3 草图）。随后依据各自轮廓和特征部件手动简化描摹为 `../public/instruments/*.svg`。SVG 采用深灰 #424242、2.6 单位圆角描边，适用于小尺寸宫格，不含位图嵌入或渐变。

生成方向：白底黑灰色简笔画，粗圆角蜡笔/马克笔轮廓，无标签、阴影、文字与渐变；从左到右、从上到下分别为电钢琴、钟琴和槌、电吉他、带波形屏的合成器、贝斯、模块合成器、弦乐合成键盘、玻璃颂钵、带麦克风的声码器键盘、肩背合成器、电子管乐器、低音音箱。

| ID | 草图主体 | 音色 |
| --- | --- | --- |
| keys | 电钢琴 | 柔和电钢 |
| bell | 钟琴与槌 | 空灵钟琴 |

| pad | 波形屏合成器 | 空气合成器 |
| bass | 贝斯 | 温暖贝斯 |
| analog | 模块与跳线 | 柔和模拟 |
