# 洞洞谱

羊子科技出品的个人六孔哨笛谱收藏夹。线上入口：https://m.mikeywa.site/ddp/ 。设置 → 关于中列出羊子科技的其他应用；页面底部无公司信息和关于入口。

## 使用

- 直接浏览和搜索，按国内流行、游戏、魔兽、影视或传统曲目筛选。星标在未登录时存本机，登录后合并到账户。
- 与 https://wcal.mikeywa.site 使用同一账户。沿用 4/6 位数字口令、四位验证尾号、创建后截图账户卡的引导；昵称、五种主题和六种字体同步。两站分别登录，非跨域自动登录。本站不维护另一套口令库，不保存体重记录。
- 打开曲谱可试听、调速、切换 C/D 调哨笛、移调、逐音编辑或直接编辑文本，再另存到私人曲库。打印可通过浏览器存 PDF。
- 听音找谱支持录音/哼唱或上传 0.3–30 秒、8 MB 内单声部音频。用本地自相关提取音高，再以移调不变的音程序列进行子序列匹配。已有旋律候选需要试听确认；无匹配可保存识别初稿。复杂混音、多声部和噪声不保证识别。
- 图片转谱用火山方舟视觉模型读取五线谱主旋律。生成结果只作为待校正初稿，音高、节奏、装饰音均可能有误。上传图片会发送给豆包；音频只在本服务器临时处理，完成即删除。
- 每个账户每日最多 10 次音频/图片识别请求，页面只在超限时显示提示。上传体积与服务并发也有限制。
- 管理入口 `/ddp/data` 及设置 → 数据看板，沿用体重日历管理密码。仅显示本产品的统计，不把另一产品的后台内容传给浏览器。

## 纯文本存储 DDP/1

曲谱实体保存 `scoreText`，不保存指法图；孔位在浏览器里由绝对音高和所选哨笛调性计算。元数据保留标题、来源、分类及是否已确认节奏。JSON 只是容器，主谱是以下可读文本：

```
DDP/1
D4:1 E4:0.5 F#4:0.5 | G4:1 R:1 A4:2
```

`音名+八度:四分拍数`，`R` 代表休止。`|` 是可选小节分隔符。当前渲染逐音展开，文本小节分隔符不单独排版；反复由传统曲集解析器在导入时展开。没有假设“存图片等于已转谱”。演奏版默认适配到两个常用八度（D 调记谱 D4–C♯6）。先整首按八度平移，跨度过大时对个别音按八度调整并标记 ↑8 / ↓8；原始文本不变，另存演奏版时才保存适配音高。第二八度用 ＋ 标记，高音 D 开最上孔，上八度 C 使用半孔。高音哨笛实际声音比记谱高八度；低音型号按记谱发声，试听与跟吹使用相同设置。变化音、半孔、叉指仍因型号有差异，不把所有第三音区都假定为同指法强吹。参考 LearnTinWhistle 指法与 Woodwind Fingering Guide 第二八度图。

## 曲库

共 1,013 份参考版本：100 份 O’Neill 1907 传统舞曲、909 份 POP909 主旋律、4 份 JE 游戏旋律。每首保留来源。不是任意歌曲的完整编配，也不提供已清理版权的商业发行承诺。

来源：[O’Neill 1907 公开转录](https://github.com/folkies/oneill)、[POP909](https://github.com/music-x-lab/POP909-Dataset)、[JE](https://github.com/zytx121/je)。后两者从相邻 NoteType 曲库中筛出主旋律；JE 未记节奏的条目始终标记 `rhythmKnown=false`。The Session 数据未采用。

NAS 203 张个人图片的原图不进入公共曲库，也不纳入 Git。用本地孔位轮廓读取生成 15,648 个音符初稿，**没有调用豆包**。所有转录均标记待校正：休止、节奏、附点、装饰、反复和半孔可能缺失。原图逐张 SHA256 核验，保留用于对照。通过一次性认领链接绑定自己的账户，之后其他账户无法访问。服务端原图通过已登录账户的所有权校验读取。

NAS 中新增两个子目录，原有图片未改变：

- `洞洞谱JPG/网站新收集-DDP文本/`：1,013 份新收集文本和来源索引。
- `洞洞谱JPG/原图转录-DDP初稿/`：203 份转录文本、清单与局限说明。

## 本地运行

```
npm ci
npm run build
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

打开 http://127.0.0.1:8796/ddp/ 。开发时 `npm run dev`，访问 5180。需要 FFmpeg。

配置项：`PORT=8796`、`DDP_DATA`、`DDP_ORIGIN`、`DDP_AUTH_ORIGIN`、`ARK_API_KEY`、`ARK_MODEL`。真实密钥仅放服务器 `/etc/ddp.env`，权限 600，禁止写入前端或 Git。开发用账户服务可指向体重日历的隔离实例。

## 验证与部署

`npm test`、`.venv/bin/python -m unittest discover -s tests -p 'test_*.py'`、`npm run build`。`ops/acceptance.py` 启动隔离账户服务和网站验证同一账户、退出重新登录后收藏、字体配色同步和后台鉴权；不会创建生产账户。`DDP_TEST_AI=1` 时仅使用自行生成的五线谱调用视觉 API，不读取 NAS 原图。

腾讯服务器 ubuntu@115.159.25.169。独立 `ddp.service` 监听 127.0.0.1:8798，Nginx 只为 m.mikeywa.site 添加 `/ddp/`。发布目录 `/opt/ddp/releases/<version>`，`/opt/ddp/current` 为活动链接，数据 `/var/lib/ddp`，虚拟环境 `/opt/ddp/venv`。部署保存 Nginx 备份并检查 `nginx -t`；验证服务、健康接口、首页资源、受保护接口和浏览器。原 NoteType 服务与路由保留。

回滚：把 current 指回上一发布并重启 `ddp.service`。首次部署前没有旧版洞洞谱时，停止该服务并恢复 Nginx 备份即可撤回入口，数据目录保留。

## 图标与互动 / 试听更新

正式图标 `public/app-icon.webp` 为 512×512、约 6 KB；浏览器图标使用 64×64 WebP，原 PNG 保存于 design/ 供后续制作，不随站点部署。互动沿用体重日历的 Motion 弹簧参数、页面切换参数、zen 音效包和按键下压反馈；图标点按可回弹，配色选中勾选带弹簧过渡，支持减少动态效果偏好。界面音效可在设置中关闭，登录后同步到同一账户。

试听使用真实 HTML audio 媒体元素播放本地生成的 WAV，支持播放会话；与界面提示音分离。该方式用于移动端的媒体播放，静音键下的实机表现仍需 iPhone/Android 设备验证。单次试听最多 15 分钟，避免生成过大的媒体文件。跳过曲首曲尾空白；默认把一组连续长休止缩到一拍，可关闭“略过长空拍”保留中间休止。

谱面与校正输入使用整数格，显示每拍格数，避免半拍被直接取整拉长。文本编辑可写 `@ticks=2` 后使用 `D4:1 E4:3`，表示半拍 D4 和一拍半 E4；旧版 DDP/1 文本仍然可读取。

## 全屏详情、播放器与跟吹

打开曲谱进入全屏详情，可通过浏览器后退返回，公开曲谱支持 `#score=曲谱编号` 链接。底部播放器显示进度，支持暂停、恢复、拖动和关闭退出。点音符暂停并定位，继续时从下一个音符开始；最后一音之后继续会重新播放。

跟吹使用浏览器 HTTPS 麦克风授权、Web Audio Analyser 与本地 YIN 音高检测，单声部稳定命中目标 ±40 音分约 80ms 后推进。连同音需要新的吐音/换气间隙，持续同一音不会连续刷过重复音。高/低音哨笛选择决定实际目标频率，严格区分八度。开始跟吹会退出试听，修改演奏设置会结束当前练习；返回、切后台、取消授权等待和麦克风断开时均释放资源。录音不上传、不保存、不调用 AI。

停止或完成时显示已完成音数和练习部分评分：音准统计稳定检测帧对当前目标的音分偏差（上限 100），节奏统计相邻命中起音间隔与原谱的相对误差；合分为音准 60% + 节奏 40%。不足两个命中音或未确认节奏的谱不提供节奏分。部分练习会明确标记，并不视为完成整首。设备延迟、环境噪声、泛音与吐音会影响识别，评分仅作练习参考。

曲谱详情快捷键：Esc 返回；左右方向键选前后音符，上下方向键按当前密度和窗口宽度移动一行（末行选择最近列）；空格播放/暂停；Enter 在暂停时继续、播放中从头重播。文本框和选择框保留自己的输入、方向键和回车行为；弹窗打开时使用弹窗自己的快捷键。跟吹时不触发播放器快捷键。
