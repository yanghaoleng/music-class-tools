用户隐私协议

更新及生效日期：2026 年 10 月 23 日

当前用户 ID

本协议说明 李老师的音乐班在提供音乐练习、AI 对话和笔记功能时，如何处理你的数据。网站会保存提交的作答与对话正文，管理员可在受权限保护的教学后台查看；未发送的输入草稿保存在浏览器本地。请勿在作答中填写身份证号、联系方式、账户密码、健康信息等个人敏感内容。

一、我们会收集哪些信息

  • 浏览器与会话标识：网站在浏览器中生成随机访客编号、会话编号和对话编号，用于关联同一浏览器的学习记录。服务端将相关标识处理后保存；“我的笔记”中的用户 ID 与后台使用的访客 ID 一致。对外展示的短用户 ID 与内部记录关联；它不是实名账号，也不会自动跨设备同步。
  • 学习行为：页面访问、开始练习的章节、所答题目、选项、判定结果、章节完成情况、页面切换与点击操作、页面处于前台时的停留时长、当前收藏题目编号与取消状态，以及发生时间，用于还原使用路径、计算正确率和教学统计。
  • 已提交的内容：你提交的简答、聊天消息、对应的 AI 回复，以及关联的题目、题目版本、选项顺序、消息顺序、时间与判定结果，用于持续对话、教学复盘、教学改进及问题排查。首次发送后，为理解对话所需的本题教练消息也可能随对话保存。
  • 网络与故障信息：建立网络连接时，服务器会接收 IP 地址等连接所需信息。应用使用处理后的网络标识执行请求限流和 AI 额度控制；故障记录包括错误类别、服务状态、请求编号、题号及耗时，不在故障日志中写入对话正文或 API 密钥。

网站不要求你提供真实姓名、手机号或邮箱，不请求通讯录、精确定位、摄像头或麦克风权限。你主动输入的个人信息可能包含在提交的对话正文中，因此请避免填写。

二、哪些内容保存在浏览器本地

网站使用浏览器本地存储保存练习进度、得分、错题状态、输入草稿、题目与对话记录、收藏笔记、上次练习位置，以及用于恢复体验的随机图标和题目顺序。部分会话标识保存在当前浏览器会话中。

未点击发送的输入草稿不会作为对话正文上传。收藏笔记主要保存在当前浏览器，当前收藏的题目编号与取消状态会同步到服务端；未提交的笔记正文不随收藏同步，但其中已提交过的对话可能同时存在于服务端。删除本地笔记或清除浏览器数据，不会自动删除服务端已有记录。更换浏览器、清除站点数据或使用无痕模式，可能导致本地记录丢失或生成新的用户 ID。

三、信息如何使用与访问

信息用于恢复练习与笔记、生成 AI 回复和简答判定、统计学习进展、改进题目和教学内容，以及定位错误、控制滥用与服务成本。管理员可以在受权限保护的后台按访客 ID 查看作答与对话记录；后台包含逐条内容，并非只有汇总统计。学习记录和对话不会在网站公开展示，也不用于广告投放或出售。

四、AI 服务与第三方处理

发送消息或提交简答时，网站会将本题资料、你的本次输入和必要的近期对话发送至火山引擎火山方舟的豆包模型，以生成回复或判定。当前聊天接口最多使用最近 12 条消息；实际发送范围还受请求长度限制。网站的访客 ID 不作为模型提示内容发送。第三方在提供服务时也会接收必要的网络连接信息。

第三方的数据处理规则请参阅火山引擎隐私政策和火山方舟大模型服务平台专用条款。本网站会自行保存上述学习与对话记录，第三方规则不替代本协议。

五、保存期限与安全措施

短用户 ID 的映射不会随学习记录自动清理，以保持编号稳定。服务端学习行为和对话记录按最近 90 天保留，超过期限的记录在后续写入新记录时执行清理。AI 调用额度记录按日使用，旧日记录在后续请求中清理。浏览器本地记录没有自动到期时间，可通过清除本站数据移除。故障日志按服务器日志策略轮转，目前未单独设定固定保留天数。

网站通过 HTTPS 提供线上访问，模型访问密钥仅保存在服务端，教学后台需要验证访问权限。随机标识经过处理并不意味着无法关联：同一用户 ID 下的学习行为和对话仍会相互关联。请妥善保管你的设备，避免在公共设备中留下敏感内容。

六、你的选择与请求

你可以选择不使用 AI 对话，仍然浏览课程并进行可用的选择题练习；简答题的 AI 判定需要提交回答。你可以在“我的笔记”中点击右下角的用户 ID，复制完整编号，用于反馈问题或请求查询、更正、删除对应的服务端记录。

目前网站没有自助删除服务端记录的入口。如需提出相关请求，可通过微信（yanghaoleng）或钉钉（杨皓棱）联系站点管理者，并附上用户 ID；请不要为反馈额外提供身份证号等敏感信息。仅清除本地数据可能使你失去原用户 ID，提出请求前请先保存该编号。

七、未成年人使用

未成年人应在监护人的指导下使用。请勿在对话中提供儿童真实姓名、学校、住址、联系方式或其他可识别个人身份的信息；监护人可通过上述渠道就相关记录提出查询或删除请求。

八、协议更新

网站的数据处理方式发生变化时，会相应更新本页面并修改更新日期。你可以随时通过首页底部的“用户隐私协议”查看当前说明。
