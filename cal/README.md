# 小节 · 音乐班排课

线上：https://m.mikeywa.site/cal/ 。图标方案：https://m.mikeywa.site/cal/icon-concepts/index.html 。

独立的一对一音乐课排课工具，面向教室管理员、多个老师、学员和家长。每次预约占用完整 60 分钟，其中 50 分钟教学、10 分钟课内休息；具体在课内何时休息由老师安排，没有额外延长预约。

## 第一次使用

1. 输入本地私有文件 `.private/正式教室访问.txt` 中的管理员口令。正式教室初始为空。
2. 在“授课老师”添加老师，设置乐器、每周授课日、开始/结束授课时间与休假日期。
3. 在“学员管理”添加学员、主课老师和购买总课时。
4. 从人员卡片生成对应访问口令，交给老师、学员或家长。口令只显示一次，重新生成会撤销该身份的旧口令和登录会话。
5. 添加课程，或设置排课日期范围后使用一句话排课/按规则排课。预览不会写入课表；确认后才保存。发现无法安排的情况会列出原因，允许用户明确确认部分结果。
6. 学员/家长可以提交预约申请，老师或管理员确认后加入课表；确认时会重新检查冲突。
7. 授课后把课程标记为“已完成”，填写课堂反馈和家长专属反馈。取消课程会释放预约课时。

不用口令也可点“进入体验教室”。每个体验创建独立空间，示例姓名和课程为虚构，右上可切换身份。体验空间 7 天后可清理，不影响正式数据。

## 月历、周历、3 天与全部列表

课表上方可随时切换四种视图，浏览器会记住上次选择。首次打开时桌面默认 7 天周历，手机默认 3 天。月历显示整个月，周历从周一到周日显示完整 7 天；3 天视图显示连续 3 天。日期箭头按当前视图翻月/翻周/翻 3 天，“今天”回到包含今天的范围。手机周历可横向滚动查看全部七天，不再强制改成列表。

“全部列表”包含所有日期的未取消课程，按日期分组，可以按学员、老师、日期或琴房搜索。四个视图使用同一份数据，也共享老师筛选。

管理员和老师可以拖动已预约的课程：月历改变日期并保留原时间；周历和 3 天视图改变日期和时间，按 15 分钟吸附。手机长按课程后拖动。每节仍固定占用 60 分钟，不能拉长/缩短。老师只能调整自己的课；学员和家长只能查看。点击课程仍可打开表单，作为拖动以外的调课方式。

保存时由服务端检查老师/学员/琴房重叠、授课日/时段/休假、过去时间和课时余额；失败会回到原位并显示原因。移动只改同一节课的日期与时间，不新建或删除课程，不改变反馈、琴房、课时等信息。已完成或取消的课程不能拖动。提交携带原日期和时间，在 SQLite 事务内检查，防止多位用户互相覆盖同一节课的调整。

日历使用 FullCalendar 6 的 DayGrid、TimeGrid、Interaction 与 Luxon 时区支持，均随站点打包，不依赖外部 CDN。统一以 Asia/Shanghai 展示、解析与保存。相关文档：[拖动与失败回退](https://fullcalendar.io/docs/eventDrop)、[自定义时长视图](https://fullcalendar.io/docs/duration)、[触屏长按](https://fullcalendar.io/docs/eventLongPressDelay)。

## 权限与课时

- 管理员：所有老师、学员、课表、总课时、邀请口令与预约。
- 老师：只管理自己的课程、预约及相关学员，查看/编辑课堂与家长反馈；不能管理人员和生成口令。
- 学员：仅自己的课、预约、课堂反馈，不返回总课时、家长备注或家长专属反馈。
- 家长：仅对应孩子的数据，额外看剩余课时、已预约课时、教室备注与家长专属反馈。

剩余课时 = 购买总课时 − 已完成课时；其中已预约课时仍占用可预约余额。可新预约数 = 总课时 − 已完成 − 已预约。一个老师、一个学员或同名非空琴房不能有重叠预约。时间与日期均按北京时间处理。

## 语义排课

借鉴相邻“智能排班表”的规则解析 → 确定性生成 → 预览 → 原子提交方式。用 `doubao-seed-2-0-mini-260428`，关闭深度思考；优先请求 `service_tier=fast`。2026-10-16 实测当前账号未开通 Fast，服务识别该特定错误后改用常规档，仍是同一个 Mini 模型。

只向模型发送用户输入、人员姓名/内部标识/主课老师和允许范围，不发送家长备注、课时账目或历史反馈。界面显示解析后的人名、日期、星期、时间、节数与排除日期供人工审核。模型不直接写数据库。

规则排课每个符合日每位学员最多一节，按日期、较早空档、所选学员顺序排入，时间候选步长为 30 分钟。可指定每人总节数；0 表示每个符合日一节。不是全局最优求解器。模糊、不可表达或矛盾的规则会要求澄清。暂不包含复杂轮转公平优化、多学生合班、微信通知、收费支付、多孩子家长账户或跨机构自助注册。

每个体验空间每天最多 20 次模型请求，正式教室 100 次，全站每天 300 次；限额在服务端校验。网络或模型失败不会悄悄变成本地猜测。

## 本地运行

```
npm ci
npm run build
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

访问 http://127.0.0.1:8802/cal/ 。Vite 开发 `npm run dev` 监听 5182，代理后端 8802。需先启动 Python 服务。环境：`CAL_DATA`（默认 data/）、`CAL_ADMIN_CODE`（首次创建才使用）、`ARK_API_KEY`、`ARK_MODEL`、`CAL_ORIGIN`。管理员口令自动生成到数据目录 `admin-access.txt`，权限 600。真实密钥、数据库、访问文件不进入 Git 或构建产物。

验证：`npm run test:backend`、`npm run test:calendar`、`npm run build`。测试覆盖身份隔离、老师/学员/琴房及休息冲突、课时余额、休假、预览过期、原子提交、重复提交、预约确认、口令轮换和请求来源。实际浏览器也验证语义预览→确认→刷新持久化和学员视角。

## 部署和恢复

腾讯云 `ubuntu@115.159.25.169`，独立 `music-cal.service`，仅监听 127.0.0.1:8802。Nginx 只为 m.mikeywa.site 添加 `/cal` 和 `/cal/`，保留 NoteType、洞洞谱等服务。

- 代码 `/opt/music-cal/releases/<version>`，活动链接 `/opt/music-cal/current`。
- 数据 `/var/lib/music-cal/cal.sqlite3`，正式管理文件 `/var/lib/music-cal/admin-access.txt`。
- 密钥 `/etc/music-cal.env`（root:root 600），运行时由 systemd 注入。
- `ops/deploy.sh` 构建、上传、创建新版本并重启服务。首次接入路由用 `ops/connect-nginx.py`，先备份原配置再检查并重载。
- 每次发布后检查服务状态、活动链接、健康接口、首页资源和受保护接口，执行线上独立体验流程；生产正式空间不写测试数据。
- 回滚：把 `/opt/music-cal/current` 指回 `/opt/music-cal/previous-release` 所记录路径并重启 `music-cal.service`，数据目录保持原位。首次上线可停止此服务并恢复 `/etc/nginx/m.mikeywa.site.before-music-cal-*.bak`，验证 Nginx 后重载。
- 备份数据库应使用 SQLite backup API（或停服务后复制），同时保存访问文件与环境配置到私有位置；本版没有自动异地备份。
